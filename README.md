# Simple Present Challenge · Klasse 6

Interaktive Übungen zu Unit 3, G8 (Aussagen und Verneinungen) und G9 (Fragen und Antworten). Beide Kapitel haben fünf Levels und einen Final Boss mit je zehn Aufgaben. Ab 7/10 ist ein Level bestanden. 7 Punkte ergeben einen Stern, 8–9 Punkte zwei und 10 Punkte drei.

## Lokal starten

1. ZIP-Datei entpacken.
2. `index.html` im Browser öffnen. `style.css` und `script.js` müssen im selben Ordner liegen.

Die Seite braucht keine Anmeldung, keine externen Dateien und keinen lokalen Server. Der Browser speichert die besten Ergebnisse auf dem jeweiligen Gerät und im jeweiligen Browserprofil. Bei lokalen Dateien hängt die dauerhafte Speicherung von den Browsereinstellungen ab. Für den Unterricht auf mehreren Geräten eignet sich der gemeinsame GitHub-Pages-Link. Die Ergebnisse bleiben dabei auf den jeweiligen Geräten.

## Auf GitHub Pages veröffentlichen

1. Bei GitHub ein neues öffentliches Repository anlegen, zum Beispiel `simple-present-challenge-6`.
2. Im Repository über **Add file → Upload files** die vier entpackten Dateien `index.html`, `style.css`, `script.js` und `README.md` direkt in die oberste Ebene hochladen. Mit **Commit changes** speichern.
3. Unter **Settings → Pages** bei **Source** den Eintrag **Deploy from a branch** wählen.
4. Als Branch `main` und als Ordner `/ (root)` auswählen. Auf **Save** klicken.
5. Sobald GitHub die Seite bereitgestellt hat, unter **Settings → Pages** auf **Visit site** klicken. Die Adresse hat bei einem Standard-Repository die Form `https://BENUTZERNAME.github.io/REPOSITORY/`.
